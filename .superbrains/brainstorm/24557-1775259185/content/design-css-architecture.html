Puter.js Texture Generation

Build-time procedural textures

How it works
  1. Build script uses puter.js canvas API to generate 256×256 transparent PNG textures
  2. Textures: panel-grain.png (subtle noise), spore-dust.png (scattered dots), mycelial-noise.png (organic pattern)
  3. Output to public/textures/ directory
  4. CSS references them: background-image: url('/textures/panel-grain.png');
  5. Opacity controlled in CSS (0.03–0.08) so they're subtle depth layers, not dominant
  6. Run via npm run textures before build, or as pre-build hook

Benefits

  • Real texture > CSS gradients for depth
  • Generated, not hand-crafted — easy to tweak
  • Tiny files (256×256 PNGs, <5KB each)
  • No runtime cost — just background-image

Risks

  • Puter.js availability — needs npm install
  • One-time build script to write
  • Textures won't animate (static overlays)
